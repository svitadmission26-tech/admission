# College Timing module
Apply `supabase/migrations/023_college_timing.sql` after migrations 001–022. Grant staff `academics.read` to view or `academics.manage` to edit, plus page access `page:College Timing` where page restrictions apply. Super admins can open College Timing from the Time Table Management group. Each college, department (blank for all), shift and weekday has one row. A row can be marked off; breaks are optional and must fit within working hours. This release stores and displays timings; existing timetable clash logic has NOT been changed to automatically enforce these timing rows. Validate timing against timetable manually until integration is implemented. Do not use production data without testing RLS and role scopes.
